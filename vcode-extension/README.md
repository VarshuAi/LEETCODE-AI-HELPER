# 👾 Antigravity IDE Companion

> Welcome to the **Antigravity IDE**, a premium workspace enhancement bundle developed by **Varshan** for Visual Studio Code!

This all-in-one extension completely transforms your editor into a high-end personal development environment with a customized Carbon Slate or macOS Dark Theme, a custom welcoming splash experience, and a built-in **Antigravity AI** assistant sidebar.

---

## ✨ Features

### 1. 🎨 Premium Workspace Themes
*   **Antigravity Carbon Slate**: A custom theme styled around elegant graphite and deep carbon HSL layers with high-contrast violet tokens.
*   **Antigravity macOS Dark**: A sleek dark mode theme matching the native macOS and Xcode styling guidelines with clean borders and Xcode-style syntax colors.

### 🚀 2. Brand Welcome Page
*   An elegant, interactive welcome tab that opens automatically on first start.
*   Includes quick actions to instantly apply the themes, configure settings, or launch the chat sidebar.

### 👾 3. Built-in Antigravity AI Chat Sidebar
*   Integrated **Antigravity AI** assistant accessible directly from your VS Code activity bar.
*   Uses Google's high-speed **`gemini-3.5-flash`** model by default to reply to questions and generate code.
*   Fully context-aware: option to automatically attach currently selected code into prompts.
*   Includes code insertion actions: with one click, inject generated code right into your active editor.

## 🛠️ Getting Started (Local Development & Testing)

To load and run the extension locally in VS Code:

1.  Open VS Code and choose **File** -> **Open Folder...** -> select `C:\Users\Varshan\Documents\antigravity\magical-hypatia\vcode-extension`.
2.  Press **`F5`** on your keyboard (or click `Run` -> `Start Debugging` in the menu).
3.  A new window labeled **`[Extension Development Host]`** will open.
4.  In the new host window:
    - Change your theme to `Antigravity Carbon Slate` or `Antigravity macOS Dark` via the Welcome screen.
    - Open the Command Palette (`Ctrl+Shift+P`), search for `Antigravity IDE: Configure Gemini API Key`, and input your key.
    - Click the custom **Antigravity Logo** in the left sidebar activity bar to begin chatting with Antigravity AI!
